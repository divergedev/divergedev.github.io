## Core Platform Features

<CardGrid>
  <Card title="Autonomous Agent Sandboxes" icon="rocket">
    Run AI coding agents (`AgentTask`) inside network-isolated Kubernetes sandboxes with attenuated **Macaroon capability tokens**, automatic linked preview environments, and live LLM cost/token metering (`POST /api/v1/agenttask/meter`).
  </Card>
  <Card title="Delta Deployments" icon="puzzle">
    Deploy **only the services that changed**. Diverge analyzes commit diffs to pinpoint impacted services and shares baseline dependencies for everything else.
  </Card>
  <Card title="Scale-to-Zero & Wake Splash" icon="moon">
    Idle PR previews scale to zero via Knative or KEDA and hibernate after idle timeouts. The Activator proxy serves a browser-friendly wake-up splash page (`--wake-splash`) during cold starts.
  </Card>
  <Card title="Interactive PR/MR Slash Commands" icon="comment">
    Manage environments and dispatch AI fixes directly from GitHub/GitLab comments with `/diverge preview`, `/diverge fix`, `/diverge extend-ttl`, `/diverge teardown`, `/diverge pause`, and `/diverge resume`.
  </Card>
  <Card title="Header & Subdomain Routing" icon="random">
    Route traffic to your preview environment with a single HTTP header or dedicated wildcard subdomain. Works natively with Istio, Envoy, Gateway API, and ConnectRPC.
  </Card>
  <Card title="Atlas Schema Management" icon="document">
    Automate database migrations and declarative schema isolation (`preview_<env>`) for each preview environment with Ariga Atlas via standalone K8s Jobs or Atlas Operator.
  </Card>
  <Card title="Built-in MCP Server & Web UI" icon="laptop">
    Connect Claude Code, Cursor, or VS Code via `/mcp` or `diverge mcp`, and visualize topologies, logs, and cost estimates (`diverge_environment_estimated_hourly_cost_usd`) in the embedded React dashboard.
  </Card>
  <Card title="Security-Hardened Architecture" icon="approve-check">
    Macaroon capability auth, OIDC SSO, RFC 7230 header validation, non-root execution, read-only root filesystems, dropped capabilities, and constant-time secret evaluation.
  </Card>
  <Card title="Pluggable Provider Registry" icon="setting">
    Extensible provider interface for routing (Istio, Gateway API), deployers (Argo CD, Direct, Knative), sandboxes (`agent-sandbox`), and databases (Postgres, Atlas, Neon, CNPG, CockroachDB).
  </Card>
</CardGrid>

## Configuration in Seconds

```yaml
# diverge.yaml — add to your repository root
version: "1"

services:
  api:
    paths: ["services/api/**"]
    image:
      repository: registry.example.com/api
      tag_template: "mr-{{.MR}}"
    helm:
      path: charts/api
  web:
    paths: ["apps/web/**"]
    image:
      repository: registry.example.com/web
      tag_template: "mr-{{.MR}}"
    helm:
      path: charts/web

defaults:
  deploy:
    mode: delta       # Only deploy services with code changes
  routing:
    mode: header      # Route via x-diverge-env header
    baseline_namespace: staging
    banner:
      enabled: true   # Injects preview banner in browser responses
  database:
    mode: schema      # Ephemeral schema isolation
    atlas:
      mode: versioned # Runs Atlas migration job on PR open
      engine: job
      migration_config_map: app-migrations
  lifecycle:
    ttl: 72h
    cleanup_on_merge: true
```

## Built for Your Stack

- **Kubernetes-native** — 100% CRD-driven (`Environment`, `PreviewGroup`, `AgentTask`), compatible with any CNCF-certified Kubernetes cluster
- **Autonomous AI Ready** — Built-in MCP server (`/mcp` & `diverge mcp`), Macaroon capability tokens, and live LLM cost/token metering
- **GitOps First** — Native integration with Argo CD Application CRs using Server-Side Apply
- **Standalone Direct Mode** — DirectDeployer applies manifests natively without requiring Argo CD
- **Kustomize & Helm** — Native support for both packaging formats
- **Service Mesh Agnostic** — Gateway API, Istio, Linkerd, Cilium, or NGINX Ingress
- **Protocol Telemetry** — HTTP/1.1, HTTP/2, gRPC, and ConnectRPC with SDK interceptors and hourly cost estimation metrics
- **Git Provider Automation** — Bi-directional webhooks, interactive `/diverge` slash commands, and MR/PR commit statuses for GitHub & GitLab
- **Local Dev Loop** — `diverge dev` hot-reloads local processes directly into remote cluster routing
- **Enterprise Security** — OIDC SSO, Macaroon capability auth, non-root distroless containers, PSS Restricted profiles, Cosign-signed images
